After any change to the project's directory structure, package dependencies, feature set, or architectural decisions, check whether `README.md` in the repository root needs to be updated. This includes but is not limited to:

- Adding, removing, or renaming packages or apps
- Changing workspace dependency edges (the Mermaid diagram in §2.1)
- Introducing new technology, tooling, or infrastructure
- Modifying FSM states, events, or transitions (the diagrams in §3.2)
- Altering the agentic workflow or recovery procedures (§3.3)
- Changing build, dev, or test commands (the "Running the Project" section)

If a change affects any of the above, update the relevant README section(s) and bump the "Last Updated" date before finishing the task.
